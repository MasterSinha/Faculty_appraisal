# Plan: Internal Security Logging System

This plan outlines the architecture, database schema, implementation points, and API design for introducing an internal security logging system into the Faculty Appraisal backend. 

The logging system is designed to provide the **Super Admin** with complete visibility into administrative changes, logins, and appraisal activities to satisfy audit and security requirements.

---

## 1. Objectives & Threat Model
The main goal is to introduce audit trails for key actions in the system to improve security and auditability. We target the following events:
- **Authentication**: Successful and failed login attempts to detect brute force, unauthorized access, and track active sessions.
- **Privileged Administrative Operations**: Additions, edits, or deletions of user profiles by administrators.
- **Workflow / Status Changes**: Submission of appraisal reports by faculty, and remarks/reviews submitted (approval/rejection) by HODs, Directors, Deans, Registrar, and VC.
- **Sensitive Operations**: DB/Storage backups generated by the super admin.

---

## 2. Database Schema Design

A new table `security_logs` will be added to the database.

### Table Schema (`public.security_logs`)
| Column Name | PostgreSQL Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | `PRIMARY KEY, DEFAULT gen_random_uuid()` | Unique log entry ID |
| `action` | `TEXT` | `NOT NULL` | The event code (e.g. `USER_LOGIN`, `ADMIN_CREATE_USER`) |
| `actor_email` | `TEXT` | `NOT NULL` | The email of the user triggering the action |
| `actor_name` | `TEXT` | `NULLABLE` | The resolved full name of the actor at the time of logging |
| `actor_ip` | `TEXT` | `NULLABLE` | IP address of the client making the request |
| `actor_user_agent`| `TEXT` | `NULLABLE` | Browser user-agent of the client |
| `target_email` | `TEXT` | `NULLABLE` | The email of the subject of the action (if applicable) |
| `details` | `JSONB` | `NOT NULL, DEFAULT '{}'` | Contextual metadata (e.g., changes made, academic year, scores) |
| `timestamp` | `TIMESTAMPTZ` | `NOT NULL, DEFAULT now()` | Precise timestamp of the event |

### Indexes
To optimize dashboard queries for Super Admins:
- Index on `action` (filtering logs by action type)
- Index on `actor_email` (auditing specific users)
- Index on `timestamp` (sorting and querying specific date/time ranges)

### C. Helper Utility and Log Retention (30-Day Auto Prune)
We will create a helper module [security_logger.py](file:///C:/Users/ruhan/Faculty_appraisal/src/setup/security_logger.py) to run database logging and prune old records. To keep performance optimal and avoid running delete queries on every API call, pruning is triggered on `USER_LOGIN` events:

```python
import logging
from datetime import datetime, timedelta
from typing import Optional, Any, Dict
from fastapi import Request
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, delete
from src.models.core import SecurityLog, FacultyProfile

logger = logging.getLogger(__name__)

async def purge_old_logs(db: AsyncSession) -> None:
    """
    Deletes logs older than 30 days from the database.
    """
    try:
        thirty_days_ago = datetime.utcnow() - timedelta(days=30)
        result = await db.execute(
            delete(SecurityLog).where(SecurityLog.timestamp < thirty_days_ago)
        )
        await db.commit()
        logger.info(f"Purged stale security logs older than 30 days.")
    except Exception as e:
        logger.error(f"Failed to purge old security logs: {str(e)}", exc_info=True)

async def log_security_event(
    db: AsyncSession,
    action: str,
    actor_email: str,
    request: Optional[Request] = None,
    target_email: Optional[str] = None,
    details: Optional[Dict[str, Any]] = None,
) -> None:
    """
    Creates a new security log entry in the database.
    Resolves the actor's full name asynchronously before saving.
    Additionally, triggers log pruning on successful login events.
    """
    try:
        # Resolve actor's name
        actor_name = None
        if actor_email:
            res = await db.execute(
                select(FacultyProfile.full_name).where(FacultyProfile.email == actor_email)
            )
            actor_name = res.scalar_one_or_none()

        # Extract request headers
        actor_ip = None
        actor_user_agent = None
        if request:
            # Check for proxy header first, fallback to client host
            actor_ip = request.headers.get("x-forwarded-for") or (request.client.host if request.client else None)
            actor_user_agent = request.headers.get("user-agent")

        log_entry = SecurityLog(
            action=action,
            actor_email=actor_email,
            actor_name=actor_name,
            actor_ip=actor_ip,
            actor_user_agent=actor_user_agent,
            target_email=target_email,
            details=details or {},
        )
        db.add(log_entry)
        await db.commit()

        # Trigger auto-pruning of older logs (>30 days) on user login events
        if action == "USER_LOGIN":
            await purge_old_logs(db)

    except Exception as e:
        # We do not want a failure in security logging to break main workflows.
        # However, we log the failure to standard logs.
        logger.error(f"Failed to write security log: {str(e)}", exc_info=True)
```

## 6. Super Admin Security Log Retrieval Endpoint

Expose a new API endpoint strictly authorized for `super_admin`.

File: [admin.py](file:///C:/Users/ruhan/Faculty_appraisal/src/api/v1/admin.py)

```python
from src.schema.core import SecurityLogListResponse

@router.get(
    "/security-logs", 
    response_model=SecurityLogListResponse,
    summary="Fetch system security logs for auditing. Super Admin only."
)
async def get_security_logs(
    current_user: CurrentUser,
    limit: int = 50,
    offset: int = 0,
    action: Optional[str] = None,
    actor_email: Optional[str] = None,
    target_email: Optional[str] = None,
    start_date: Optional[datetime] = None,
    end_date: Optional[datetime] = None,
    db: AsyncSession = Depends(get_db),
):
    """
    Retrieves system audit logs. Only accessible to users with the 'super_admin' role.
    Supports filtering and pagination.
    """
    _check_super_admin(current_user)

    from sqlalchemy import select, func, and_
    from src.models.core import SecurityLog

    # Construct filtering conditions
    conditions = []
    if action:
        conditions.append(SecurityLog.action == action)
    if actor_email:
        conditions.append(SecurityLog.actor_email.ilike(f"%{actor_email}%"))
    if target_email:
        conditions.append(SecurityLog.target_email.ilike(f"%{target_email}%"))
    if start_date:
        conditions.append(SecurityLog.timestamp >= start_date)
    if end_date:
        conditions.append(SecurityLog.timestamp <= end_date)

    query = select(SecurityLog)
    count_query = select(func.count(SecurityLog.id))

    if conditions:
        query = query.where(and_(*conditions))
        count_query = count_query.where(and_(*conditions))

    # Order by timestamp descending (newest first)
    query = query.order_by(SecurityLog.timestamp.desc()).limit(limit).offset(offset)

    # Execute queries
    count_result = await db.execute(count_query)
    total = count_result.scalar_one()

    log_result = await db.execute(query)
    logs = log_result.scalars().all()

    return {"total": total, "logs": logs}
```
