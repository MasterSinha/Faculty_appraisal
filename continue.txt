## 3. Current Active Issue (Redirect to Login)
* **Symptom**: Clicking on a restored file link in the frontend redirects the browser to `http://10.100.0.23:3000/login`.
* **Root Cause**: The database was restored from a backup and contains relative URLs (e.g. `/api/v1/upload/view/...`). When clicked on the frontend (port 3000), the browser resolves them relative to the frontend's origin (`http://10.100.0.23:3000/api/v1/upload/view/...`). The frontend dev server doesn't host this, falling back to React Router which triggers the auth guard redirect to `/login`.
* **Verification**: Manually accessing the absolute URL directly in the browser (`http://10.100.0.23:8000/api/v1/upload/view/...`) successfully loads the file from the VM.
